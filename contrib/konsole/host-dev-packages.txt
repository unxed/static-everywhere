# contrib/konsole/host-dev-packages.txt -- the host header contract.
#
# Every -dev package the build job installs, hence every host header the
# compiler may see. tools/stage-host-includes.sh stages the dependency
# closure of these -- minus any top-level include name a Conan package
# vendors -- into ONEBIN_HOST_INCLUDE_DIR, and the zig wrappers redirect
# every /usr/include on the command line, and their own fallback, to that
# stage. A host library not listed here is invisible to the compile
# however the search path is arranged: this is how konsole stops
# compiling against the host's ICU 74 while linking Conan's ICU 78.
# The workflow reads this file for apt; the preflight asserts no drift.
