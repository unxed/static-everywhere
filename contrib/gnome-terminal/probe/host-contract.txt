# contrib/gnome-terminal/probe/host-contract.txt
#
# The declared soname contract for a GNOME Terminal build, checked by
# gt-probe against /proc/self/maps at runtime.
#
# This is deliberately a *runtime* contract, not a DT_NEEDED list. tools/audit.sh
# reads DT_NEEDED, which cannot see anything arriving by dlopen -- and for a GTK
# application the dlopen'd set is larger than the linked set (probe report II:
# 4 DT_NEEDED entries, 92 mapped objects). Both checks are needed; neither
# subsumes the other.
#
#   require <prefix>   must be mapped after the probe has exercised everything.
#                      A prefix, because the loader maps libvte-2.91.so.0.7600.0
#                      while the contract is about libvte-2.91.so.0.
#   allow   <prefix>   permitted to appear, not required to. Host contract
#                      (Layer 3) and transitive driver closure.
#
# Anything mapped and matching neither is reported as undeclared, and is an
# error under --strict. That report is the point of the file: for a bundled
# build every `require` line below becomes something we ship rather than
# something we find, and the difference between the two lists is the work.

# ---- Layer 1: code. In a bundled build these all move inside our binary,
#      and every one of these lines is then expected to STOP matching.
